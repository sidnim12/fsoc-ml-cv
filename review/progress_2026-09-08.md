The fusion weights are validated and must sum to `1.0`.

## Design Decisions

The classifier checkpoint is loaded once when `SingleFramePipeline` is created. It is not reloaded per candidate or frame.

Candidate crops reuse:

```text
prepare_patches.crop_with_padding()
```

This keeps inference crop behavior compatible with CNN training.

The BGR crop is converted to RGB before tensor normalization, matching the training path where saved BGR patches were loaded and converted to RGB.

All valid candidates are kept. The pipeline records these values for every candidate:

```text
correct_probability
false_probability
predicted_class
cnn_confidence
cv_baseline_score
fused_score
```

Candidate ranking uses:

```text
fused_score = 0.80 * correct_probability + 0.20 * baseline_score
```

The accepted target must satisfy:

```text
correct_probability >= confidence_threshold
```

The starting threshold remains:

```text
0.55
```

## Coordinate Convention

Image error:

```text
image_error_x_px = target_x - frame_center_x
image_error_y_px = target_y - frame_center_y
```

Image-space meaning:

```text
Right = positive X
Left = negative X
Down = positive Y
Up = negative Y
```

Control error:

```text
control_error_x = image_error_x_px / frame_center_x
control_error_y = -image_error_y_px / frame_center_y
```

Control-space meaning:

```text
Right = positive pan
Left = negative pan
Up = positive tilt
Down = negative tilt
```

Normalized control errors are clamped to:

```text
[-1, 1]
```

## Phase 7 Design Notes

Temporal verification defaults to persistence mode:

```text
history_window: 5
min_confirmations: 3
association_radius_px: 25
blink_enabled: false
```

Blink-pattern support is present but intentionally disabled by default because the current synthetic dataset does not yet encode a reliable beacon blink ID pattern.

The Kalman filter uses a constant-velocity image-space model:

```text
state x = [x, y, vx, vy]
measurement z = [x, y]
prediction: x' = F x
correction: x = x' + K(z - Hx')
```

Candidate association uses the predicted Kalman position. Candidates outside the gate are rejected.

```text
association_gate_px: 60
association_confidence_weight: 0.40
association_position_weight: 0.60
association_score = 0.40 * fused_score + 0.60 * position_score
```

Lock states:

```text
SEARCHING  - no usable target candidate
ACQUIRING  - target candidate is being confirmed
LOCKED     - target is temporally verified
COASTING   - target is missing briefly, so prediction is used
LOST       - target has been missing too long
```
