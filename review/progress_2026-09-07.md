## 2. Phase 2 - Image Preprocessing

Implemented:

```text
src/preprocessing.py
```

Purpose:

Convert original camera frames into clean binary images for bright-object detection.

Processing flow:

```text
Original BGR image
  -> grayscale
  -> optional contrast normalization
  -> Gaussian blur
  -> thresholding
  -> morphological opening and closing
  -> binary image
```

Supported threshold methods:

```text
fixed
otsu
adaptive
```

Important output folders:

```text

outputs/preprocessing/comparisons/
```

Full dataset command:

```powershell

```

## Current Limitations

The full dataset is synthetic. The classifier must later be tested on Unity-generated frames under more realistic lighting, movement, exposure, blur and noise.

The current CNN can confuse real and false beacon-like patches because they are intentionally visually similar in 32 x 32 crops. This is expected before temporal verification and Unity-domain testing.

## Future Plan
